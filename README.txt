BAS LAB MUSIC / ASSET FOLDERS

โครงสร้าง:
sound/   = เพลงพื้นหลัง song1.mp3 ถึง song10.mp3
png/     = รูปภาพ
scream/  = เสียงกรี๊ด
video/   = วิดีโอ jumpscare

ระบบเพลง:
- เล่นเพลงต่ออัตโนมัติและวนไปเรื่อย ๆ
- เปลี่ยนเพลงเองได้จากปุ่ม ⚙️ ตั้งค่าเพลง
- ปรับเสียง 0-100% ได้
- จำเพลงและระดับเสียงล่าสุดด้วย localStorage
- ถ้าเบราว์เซอร์บล็อก autoplay เพลงจะเริ่มเมื่อผู้ใช้คลิก/แตะ/กดปุ่มครั้งแรก

การเพิ่มเพลง:
ใส่ไฟล์ MP3 ใน sound/ และตั้งชื่อ song1.mp3, song2.mp3 ... song10.mp3
